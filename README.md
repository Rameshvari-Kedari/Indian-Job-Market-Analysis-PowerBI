# Indian Job Market Analysis

## Project Overview

The Indian Job Market Analysis project is an interactive Power BI dashboard
designed to analyze recruitment trends across India.

The dashboard provides insights into job openings, companies, salaries,
industries, locations, work modes, applicants, and hiring trends.

## Dashboard Pages

### 1. Overview
- Total Jobs
- Total Companies
- Total Openings
- Average Salary
- Total Applicants
- Jobs by Role
- Openings by Industry
- Jobs by Work Mode
- Jobs by Location
- Monthly Hiring Trend

### 2. Salary & Company
- Company-wise Hiring
- Applications vs Salary
- Highest Paying Jobs
- Company by Industry
- Salary by Experience

### 3. Insights
- Top 5 Hiring Companies
- Hiring trends
- Industry-wise openings
- Work mode analysis
- Location-wise hiring
- Salary and experience relationship

## Tools & Technologies

- Power BI
- Power Query
- DAX
- Excel / CSV
- Data Visualization

## Key Insights

- Business Analyst has a high number of job postings.
- Hiring activity varies across major Indian cities.
- Hybrid work mode represents a significant share of jobs.
- Salary generally increases with experience.
- Hiring trends vary across months.
